# Portfolio_
My Portfolio that showcase my skills and achievements as a pre final year student.

## Tech Stack
- Next.js (App Router) + React
- TypeScript
- Tailwind CSS (custom theme)
- Framer Motion (section/card animations)
- Lucide React (icons)
- Vercel-ready deployment (Next build output)
## What’s Included (Pages / Sections)
- `Home (/ )`: Hero + About + Education + Projects + Skills + Certifications + Interests + Contact
